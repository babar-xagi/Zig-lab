# Zig Lab Vision

## Purpose

Use working code, repeatable tests, measurements, and preserved evidence to explore difficult Zig tooling ideas.

## Main themes

### Interactive Zig
Notebook-like and REPL-like workflows while preserving Zig's native compilation model.

### Fast iteration
Explore:
- fast-path evaluation
- `comptime` specialization
- compiler caching
- incremental compilation
- artifact reuse
- persistent execution

### Browser and WebAssembly
Explore:
- in-browser execution
- cached WASM artifacts
- offline behavior
- local vs remote compiler bridges

### Systems-oriented notebooks
Potential features:
- memory layouts
- binary structures
- benchmarking
- compile-time evaluation
- native code generation
- compiler diagnostics

## Non-goals

Initially Zig Lab is not:
- a production IDE
- a replacement Zig compiler
- a promise that every experiment becomes a product

Failed experiments are valid results.
