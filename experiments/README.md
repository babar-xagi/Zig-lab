# Experiments

Each experiment gets a permanent ID.

Example:

```text
EXP-001-hybrid-execution-cache/
```

## README template

```markdown
# EXP-NNN — Title

## Status
PLANNED | RUNNING | COMPLETED | PAUSED

## Question

## Hypothesis

## Baseline

## Environment

## Implementation

## Procedure

## Raw results

## Interpretation

## Result
SUPPORTED | REJECTED | MIXED | INCONCLUSIVE

## Limitations

## Next experiment
```

Do not rewrite failed experiments out of history.
